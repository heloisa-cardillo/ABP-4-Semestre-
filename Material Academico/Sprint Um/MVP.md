### MVP — Minimum Viable Product

### Sprint 1 — Estrutura base: autenticação, banco de dados e ambiente padronizado

Com a primeira Sprint, o sistema já tem a estrutura base para o controle de acesso: a API permite fazer login com autenticação via JWT e se comunica com o banco de dados, onde ficam as tabelas de usuários, locais, terminais, autorizações e eventos. O ambiente está padronizado com Docker e conta com integração contínua e automação de testes.
