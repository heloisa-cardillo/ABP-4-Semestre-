# Controle de Acesso com QR Code e NFC

Sistema que libera uma catraca por QR Code rotativo (lido pelo app) ou por tag NFC. A decisão de liberar ou negar é sempre do backend.

## Componentes e tecnologias

- **App móvel:** React Native (Expo) + TypeScript
- **Backend:** Node.js, Express, TypeScript, Prisma, PostgreSQL
- **Terminal de acesso:** ESP32 (C++ com PlatformIO), display, leitor NFC, GPS, servo e buzzer
- **Comunicação:** REST com JWT e MQTT com TLS
- **DevOps:** Docker e GitHub Actions
